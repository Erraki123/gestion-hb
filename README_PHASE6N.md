# ATLAS 6N — Contacts proposés dans Fiche Entreprise

Local only, admin-only existing Prospection view. Reads `storage/app/prospect-imports/atlas-contact-review.csv` generated by 6K/6M.

## Installation

Extract this archive into your Laravel project root. Run `powershell -ExecutionPolicy Bypass -File .\INSTALL_ATLAS_PHASE6N.ps1`.

## What it does

- Shows **unverified** OSM contact suggestions in existing ATLAS modal, with provenance link, for matched company, city and original `source_url`.
- **Does not** update the CRM, send messages, or automatically accept contacts.
- Displays no suggestion for missing, ambiguous or rejected records.
- Validates HTTPS provenance and contact formats. CSV rows are treated as untrusted.
- Backups existing view. If Blade caching fails, restores view and service.

## Test

Open `/prospects` as Admin, select `Clinique Sebou` (one of the 5 imported names in the user's last test). Open `Voir la fiche`. You should see `Coordonnées proposées — à vérifier` and the OSM phone if source URL identity matches. Other 4 clinics may have no evidence.

## Limits

No contact is "verified"; OSM content can be outdated. Other 55 selected businesses remain in the CSV only, not `discovered_prospects`. The product does not currently present source freshness because it is not provided by CSV. Do not call or email automatically.
